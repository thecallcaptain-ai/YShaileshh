# YShaileshh Website

A clean, responsive personal portfolio starter.

## Files
- index.html — website structure/content
- style.css — design and responsive layout
- script.js — mobile navigation and current year

## Run locally
Open `index.html` in a browser.

## Before publishing
1. Replace the placeholder email in `index.html`.
2. Update project descriptions and social links.
3. Add your own profile photo if you want one.
4. Firebase can be connected later for contact forms, authentication, analytics, or a dynamic project/admin system.

The site is static, so it does not require a backend to run.
